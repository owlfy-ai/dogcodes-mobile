# DogCodes 手機端 UI 概念設計

本次為全新資訊架構與高保真視覺設計，不沿用現有 Flutter 頁面與交互。設計覆蓋「未來」功能範圍，圖中功能不代表已實作；沒有修改桌面或手機執行程式碼。

## 視覺原則

- 亮色主畫布純白 #FFFFFF；暗色主畫布純黑 #000000。卡片、程式碼與輸入框可以用極淺／極深中性色做必要層次，不以灰色或綠色取代整體背景。
- 延續 PC 的簡潔文字、細線圖示、開放式 Agent 回覆、緊湊工具活動、圓角輸入區與細分隔線，不製作大型數據儀表板或裝飾插畫。
- 綠色沿用 PC：亮色 #78A91F、暗色 #B7F34C。只用於主操作、選中狀態和小型狀態標記；狀態同時用文字表達。
- 內文與大多數按鈕使用黑白灰。紅綠差異只在 Git 增刪等有語義的位置少量出現。
- 細節頁使用返回導航，減少全域導覽佔用。可點按區域至少 44pt，文字可動態放大。程式碼可橫向捲動，不為塞入手機而縮小至難以閱讀。

## 全域架構

底部四個入口，固定順序：會話、工作區、待處理、電腦。

| 入口 | 職責 |
|---|---|
| 會話 | 跨電腦／項目會話、搜尋、建立與續接；主要工作入口 |
| 工作區 | 項目文件、變更、審查、終端、運行配置及預覽 |
| 待處理 | 待審批與待回答集中處理；按電腦、項目和會話歸組 |
| 電腦 | 已綁定設備、在線狀態、Agent 安裝／額度、遠控與配對入口 |

選中的電腦／項目為可見上下文。全域會話可以跨設備聚合；具體終端、文件、審查和運行始終綁定一台 PC 的一個項目，不因切換頁面隱式切換執行對象。

「電腦」頁每個設備區塊的層級固定為：設備名稱／在線狀態 → 設備級「遠程桌面」入口 → Agent 安裝狀態、額度及會話入口。遠控直接連接該電腦的屏幕和鍵鼠，不要求選擇 Agent，也不依賴任何 Agent 是否已安裝或正在執行任務；同一電腦只放一個遠控入口。離線時入口停用並標明離線；鎖屏時依下述鎖屏規則處理。

## 十二個核心畫面

| 編號 | 畫面 | 主要覆蓋 |
|---|---|---|
| 01 | 會話 | 搜尋、狀態、項目／電腦篩選、新建、置頂／歸檔入口 |
| 02 | 對話 | 串流、思考／工具活動、文件改動、停止／繼續、附件與 Agent 選擇 |
| 03 | 新會話／選項 | 項目選擇、Agent／模型／思考強度、權限模式、任務附件 |
| 04 | 待處理 | 原操作詳情、單次／範圍授權、拒絕、結構化問答 |
| 05 | 工作區 | 項目切換、文件／變更／終端／運行入口、審查、運行配置 |
| 06 | 變更／Git | 文件列表、單欄 Diff、暫存／取消暫存、提交／推送、AI 審查與修復 |
| 07 | 文件 | PC 項目文件只讀瀏覽、搜尋、正文預覽、任務附件入口 |
| 08 | 終端 | 多終端、新建／切換／關閉、輸入、輸出、常用控制鍵 |
| 09 | 運行與預覽 | 配置選擇／編輯、啟停／重啟、輸出、App 內網站預覽與瀏覽器入口 |
| 10 | 遠程桌面 | 畫面、觸控／觸控板、鍵盤、橫屏、切屏、手動雙向文本／圖片剪貼板 |
| 11 | 電腦／Agent | 多電腦、掃碼配對、設備狀態、已安裝 Agent 與額度、撤銷綁定入口 |
| 12 | 偏好設定 | 純白／純黑／系統主題、通知／靜音、離線快取、保持喚醒 |

兩組畫面分別製作亮色與暗色稿，共四張圖。不是十二個頂層入口；Agent／模型、配對和設定等採用次級畫面或底部面板。

## 圖中未展開但必須承接的操作

- 會話更多選單：重新命名、置頂、歸檔、Fork、刪除；會話內 Agent 切換和上下文使用狀態。
- 新建項目：選擇 PC 已有目錄，保留完整路徑／電腦辨識；不提供手機隨意寫入任意文件。
- 審查：範圍／Agent 選擇、串流、取消、問題定位、選中問題後「開始修復」，修復回到主會話。
- Git：分支與比較範圍、文件多選、暫存／取消暫存、丟棄確認、提交說明、Commit／Commit & Push，推送失敗時只重試推送。危險操作顯示具體影響範圍。
- 審批：發起 Agent、項目、完整命令／路徑／Diff、授權範圍都可展開；多項並發請求保留獨立結果，禁止沒有範圍資訊的「全部允許」。
- 終端：以持久身份在打開時自動恢復。不要提供「恢復終端」按鈕；終端頁的 x 表示關閉當前終端，離開頁面和關閉終端是兩個動作。
- 項目運行：配置跟隨 PC 項目共享，預覽支援網頁交互和熱更新；輸出區可展開，不在主流程暴露代理或通道配置。
- Agent 安裝、升級、配置和登入：手機提供狀態／額度只讀；需要管理時引導進入已授權的遠控，不在手機重複建立完整管理控制台。
- 遠控：Windows、macOS、Linux X11／Wayland，逐個顯示器切換；首版不傳系統聲音。鎖屏仍可管理 Agent，遠程解鎖不納入首版。
- 不新增帳號登入、團隊協作、公開聊天、操作記錄等既定範圍外入口。雲資料庫、Redis、operationId、加密演算法等不出現在使用者操作流程。

## 異常與跨端狀態

- 在線、連接中、離線、最後同步時間要有文字狀態，不能只靠圓點顏色。
- 離線可讀已快取的最近會話；草稿與待發送模型／思考強度各端獨立，不能互相覆蓋。
- 發送後結果未知，保留原內容並提供「核實結果」，不自動再次發送。重試沿用原操作，不能在界面上偽裝已完成。
- 待處理審批若在 PC 已處理或已過期，手機更新結果並停止提供舊按鈕。
- 每台電腦／每個會話可靜音；通知只提醒，點開核實後在 App 內決策。
- 撤銷綁定需說明是哪台電腦／哪部手機；斷線／離開頁面不等於取消 PC 上的任務。
- 電腦鎖屏時，會話、審批和其他可用的 Agent 業務繼續提供；遠控顯示「電腦已鎖定，Agent 操作仍可用」，暫停畫面與輸入，不展示遠程解鎖入口。電腦睡眠和離線另行標示。
- 審查因網路中斷而停止時顯示「審查中斷」，保留已收到內容並提供重試；不能標為已完成，也不能把沒有收到問題誤認為審查通過。

## 產物與生成方式

使用內建 image_gen 作圖，沒有使用 CLI/API fallback。提示詞以同目錄 *.prompt.txt 保存，可供後續精修與 UI 開發參考。PNG 為設計討論稿，不是已完成的 App 截圖。
