# 手機端接續清單

## 2026-10-18 已完成的首條鏈路

- 原生 Rust Noise 與 Dart FFI 打包到 iOS/Android；Android 目前僅 ARM64。兩平台模擬器真實系統安全存儲/加密測試通過。
- PC daemon 配對 UI、系統 keyring、配對 journal、出站在線與重連；服務匿名路由登記，手機不登入帳號。
- 真實 PC 項目/會話、新任務、就緒且啟用的 Agent、模型/思考強度、事件驅動時間線、選項式權限審批。
- 寫前保存完整原請求/operationId、未知結果保留、顯式核實/原身份重試、放棄栅欄、審批回執/版本失效栅欄。
- 重連使用雙方公鑰 pin，PC 從認證通道生成 PairedDevice；撤銷使既有連線不能繼續接納請求/交付資料。
- 隔離真實 Core + 合成 Agent 完整驗收通過，執行一次任務；不是付費真實 Agent 或公網驗收。12 項普通測試、3 項主機原生 FFI 測試、每平台 1 項模擬器整合測試通過。

## 2026-10-18 UI 改版

- 依 `docs/design/mobile-2026-10-18` 重建資訊架構：底部「會話／工作區／待處理／電腦」，詳情頁返回導航；亮色純白、暗色純黑，偏好設置可選跟隨系統／亮色／暗色。
- 多電腦連線集中於 `HostHub`：跨電腦會話列表（搜尋、按電腦篩選、按日期與項目分組）、集中待審批與待核實操作、離線顯示最後同步時間；新會話／對話／Agent 模型思考強度底部面板沿用原寫前保存與核實/重試/放棄流程。
- 電腦頁每台設備只有一個設備級「遠程桌面」入口（尚未開放，停用），Agent 安裝狀態只讀。
- 工作區的文件/變更/終端/運行與 AI 審查僅顯示入口與「尚未開放」說明，待 PC 網關開放方法後接入；14 項普通測試以合成 PC 資料覆蓋新頁面，iOS 模擬器亮/暗色目視核對。

## 2026-10-18 對接真實 PC 業務

- PC 網關（`remote-control` 分支）：同一連線可訂閱多個項目（每項目一條、上限 32）；配對/重連回執帶電腦名稱（僅顯示用）；開放只讀 `quota_snapshots_for`（手機不能強制刷新）；配對邀請等待手機握手直到 QR 到期（原 15 秒，掃碼稍慢即 410 失敗）。
- App：電腦名稱、手機停止任務（`cancel_turn`，流版本衝突時對同一 run 重試）、結構化問答表單、Agent 額度、「從手機移除」電腦。
- 證據：server `gateway_smoke.py` 對真實 PC Core 通過配對/發送/串流/審批/停止/額度/重連/撤銷；iOS 模擬器 `integration_test/pc_control_test.dart` 以真實 UI 完成同一鏈路。仍為合成 Agent，非付費真實 Agent、真機或公網驗收。
- 使用者桌面版需合併 `remote-control` 分支後才有「連接手機」；合併由維護者決定。

## 2026-10-19 手機直連

- 協商失敗保留中繼；直連斷開重新認證中繼，不重播失敗操作；項目訂閱重建並拒絕舊代次快照。支援 TURN 短期憑據續期協商。
- iOS、Android 模擬器真實 PC fixture 的 P2P/加密分片/串流/中繼回退已通過；後續平台驗證記錄見 [傳輸說明](p2p-transport.md)。仍需跨網真機及官方 TURN 驗收。
- PC 與 server 已補網關/桌面/剪貼板/預覽/通知等後端方法；下面範圍表的「待完成」指手機介面與端到端整合，不能再解讀成 PC 完全沒有這些能力。

## 2026-10-19 工作區、遠控與會話管理

依 PC 網關新開放方法接入（`lib/core/pc_api.dart` 統一封裝）：
- 文件（07）：項目只讀瀏覽、搜尋、行號預覽/圖片預覽。
- 變更（06）：分支、範圍（未提交/已暫存/未暫存）、+/− 統計、手機端 Myers 行級 diff、暫存/取消暫存、提交、提交並推送（PC 工作流）、推送/拉取/同步、AI 提交說明；結果未知時以原 operationId 查回執。
- 終端（08）：多終端、持久重連（按偏移續讀）、× 關閉並確認；輸入改為整行送出以避免手機輸入法重複提交組字。
- 運行與預覽（09）：讀取 PC 運行配置、啟動/停止/重啟、輸出、偵測本機端口；預覽經手機回環代理（HTTP + WebSocket 長輪詢）在 App 內 WebView 開啟。
- 遠程桌面（10）：設備級入口，JPEG 拉幀（≤5fps）、點擊/右鍵/雙指滾動、鍵盤、按鍵列、雙向文字剪貼板、切屏、鎖屏提示。
- 電腦頁保持喚醒開關；會話重命名/刪除。
- 證據：iOS 模擬器連使用者真實 PC 目視驗證文件、變更 diff、終端（git log）、運行頁、遠程桌面；32 項測試通過。未在模擬器中執行提交/推送、啟動 dev server 或遠控輸入，以免改動使用者資料。

## 2026-10-21 會話組織、Fork 與歷史搜索

- 會話列表分為「當前會話／已歸檔」，置頂獨立排列；每行及對話的更多菜單可置頂、取消置頂、歸檔、取消歸檔。使用 PC `history_preferences` 與帶版本的 `set_history_preferences`，不覆蓋其他會話/項目/排序。已歸檔會話仍可打開；PC 更新的較舊回包不能覆蓋新狀態。
- Fork 頁選擇具體歷史輪次及 workspace/worktree，運行中的來源會話等待結束。workspace 共用當前文件；worktree 由 PC 恢復輪末快照，缺快照時不偷偷退回 workspace。新 taskId 在發送前保存，回執丟失後核實/重試仍用原 ID、輪次與環境；PC 已完成但目標不可用時不重新創建。
- 列表頂部可在當前電腦/項目範圍跨會話搜索正文；單會話更多菜單可只搜該會話。PC API 為 task-scoped，手機最多 4 個查詢並發，各會話凍結 throughSequence 分頁；過期查詢不污染新關鍵詞，離線/查詢失敗可單獨重試。結果可讀完整記錄並打開對應輪次。不包含思考或附件正文，不是雲端內容索引。
- 原增量流式合併已保留；修正超過 4,000 事件後舊快照無法補齊卻覆蓋已顯示回答，以及換路前快照晚到的邊界。正在查看的項目優先訂閱，不再因位於概覽前 16 個項目之外而只能定期刷新；多次切換會釋放舊訂閱。
- 設定/Fork 待核實操作沿用待處理卡片；不自動重放。版本衝突不自動套用到別人的新設定，需核實後明確結束原跟蹤，再發新操作。結束跟蹤不取消已受理的操作、不刪 Worktree。
- 驗證：66 項 Dart/Widget 回歸與靜態檢查通過；server `tools/gateway_smoke.py` 用獨立臨時 PostgreSQL 資料庫、隨機 Redis namespace、臨時 PC Core 和合成 Agent，通過真實加密中繼的置頂/歸檔/恢復、搜索分頁及 workspace Fork，連同原發送/串流/審批/停止/重連/撤銷。worktree 選項與回執競爭使用確定性測試，本輪未做真機、公網或真實供應商對話。
