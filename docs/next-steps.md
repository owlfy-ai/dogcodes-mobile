# 手機端接續清單

## 2026-10-18 已完成的首條鏈路

- 原生 Rust Noise 與 Dart FFI 打包到 iOS/Android；Android 目前僅 ARM64。兩平台模擬器真實系統安全存儲/加密測試通過。
- PC daemon 配對 UI、系統 keyring、配對 journal、出站在線與重連；服務匿名路由登記，手機不登入帳號。
- 真實 PC 項目/會話、新任務、就緒且啟用的 Agent、模型/思考強度、事件驅動時間線、選項式權限審批。
- 寫前保存完整原請求/operationId、未知結果保留、顯式核實/原身份重試、放棄栅欄、審批回執/版本失效栅欄。
- 重連使用雙方公鑰 pin，PC 從認證通道生成 PairedDevice；撤銷使既有連線不能繼續接納請求/交付資料。
- 隔離真實 Core + 合成 Agent 完整驗收通過，執行一次任務；不是付費真實 Agent 或公網驗收。12 項普通測試、3 項主機原生 FFI 測試、每平台 1 項模擬器整合測試通過。

## 2026-10-22 远控视频、工作区与配对恢复

- 普通中继远控也拥有独立的已认证连接，主业务连接升级直连不再关闭画面租约；视频大帧不再与 Agent 消息/审批共用业务连接。远控连接到期前重新协商；后台停止远控并释放键鼠，前台重新建立租约，旧输入队列不重放。建立连接超时或退出后的迟到结果会释放。
- 无首帧（8 次心跳）或 PC 继续送帧但手机连续 5 次心跳没有解码进展时重开 JPEG 模式；PC 的编码器初始化/运行错误会回传。中继 FPS 读取平台解码器实际输出计数，不再以提交解码次数代替。静止画面不按零 FPS 判定故障。
- 累计 ACK 成功后才推进已确认序号；失败按 0.2–3.2 秒间隔重试。大关键帧允许在空窗口单独发送，硬上限 4 MiB；其余帧仍受字节预算和 8 帧窗口限制。切屏重置视频代次/窗口，手机过滤旧代次、重建解码器并应用新尺寸。
- Git 提交、提交并推送、推送/拉取/同步，以及暂存/取消暂存均在发送前保留原 UUID、仓库、冻结比较、文件列表和说明。核实是只读的，提交成功不等于推送完成；失败推送只沿 PC 持久工作流的预留身份继续。Git/索引结果未知不会重新造请求；结束跟踪先在 PC 关闭原工作流，再清除手机记录。变更页和逐轮提交均接入；审批/会话的迟到结果同样不能清掉较新的本机待核实记录。
- 手机运行配置支持选择 Agent 分析、对自定义修改确认覆盖、重命名、固定/取消固定和删除。所有修改冻结原配置代次并保存 UUID；分析已被 PC 持久受理后释放手机待确认槽，进度从 PC 目录状态读取，重试不会启动另一轮分析。
- 终端与项目启动在发送前保存原 UUID/原命令配方；通过 `terminal_launch_intents` 读取 PC 原始请求和终端回执，核实时不启动进程。结束跟踪必须先在 PC 持久取消未受理请求；这与启动共享接纳锁，Core 重启后仍禁止迟到请求执行。已启动的终端继续保留。电脑未支持恢复协议时，能力检查会在写入前要求更新。
- 打开的运行/终端页面监听连接代次，换路后按原终端 ID 读取电脑缓冲，不重放键盘输入；过时页面读取不能覆盖新连接结果，异步错误不会写入已释放的通知器。不同目录的同名命令分别选择；重启必须确认旧进程结束且原配方未改变，停止失败不会启动第二个进程。
